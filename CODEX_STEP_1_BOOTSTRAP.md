# AI Software Factory — Step 1 Bootstrap

This repository currently contains the step 1 technical foundation only.

Implemented:

- installable Python package using a `src/` layout;
- Typer CLI exposed as `factory` and `python -m ai_software_factory`;
- `factory version`;
- `factory doctor` minimal diagnostics;
- `factory init` placeholder with no side effects;
- pytest, Ruff, and MyPy configuration;
- initial documentation and environment example.

Not implemented until later steps:

- real project initialization;
- repository scanning;
- CrewAI execution;
- model provider integration;
- generated project specifications or context.
